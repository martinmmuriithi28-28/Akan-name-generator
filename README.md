# Akan Name Generator

## Project Description

The Akan Name Generator is a simple and interactive web application that determines a user's traditional Akan name based on their date of birth and gender. Akan names originate  from the Akan people of Ghana,
where children are traditionally named according to the week they are born. This project demonstrates the practical uses of HTML , CSS and JavaScript by collecting user input, performing date calculations, validating
form results and displaying personalized results in a clean and user friendly interface.

  a gender
